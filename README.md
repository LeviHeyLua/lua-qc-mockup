# Lua QC mockup

A shareable, interactive HTML walkthrough of agent quality-control setup, test runs, conversations, human review, and reports.

All test data, generated scenarios, Miro boards, and Linear tickets are simulated. There are no live service connections. Demo state is held in the browser's memory and resets on refresh.

## Hosting and updates

GitHub Pages serves `index.html` from the root of the `main` branch. Push changes to `main` to update the same public URL.

This repository contains only the demo, not the source architecture documents or the tested agent.
